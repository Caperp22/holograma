Holograma con tus manos

Apoya el celular para tener las dos manos libres y ponte a unos 40–60 cm de la cámara.
  • Pellizca (pulgar + índice) para agarrar el objeto y moverlo.
  • Cierra el puño y muévelo para girarlo.
  • Pellizca con las dos manos: sepáralas para agrandar, júntalas para achicar y gíralas como un volante.
  • Modo pirámide: 4 vistas para poner una pirámide de acrílico encima (Pepper's ghost).
