Holo Rubik

Juega con el cubo como si lo tuvieras en las manos:

  • ☝️ Apunta con el índice: el cuadro que tocas se ilumina.
  • 🤏 Pellizca y arrastra: esa capa te sigue (también las del medio).
  • ✊ Puño y muévelo: gira todo el cubo. Abre la mano para soltarlo.
  • ✌️ deshacer · 👍 hazlo por mí (sostenidos 1 s). Toca «Gestos» para ver todos.

Gestos

  • ☝️ Índice estirado: apuntar. Ilumina el cuadro que tocas y presiona botones si lo dejas quieto.
  • 🤏 Pellizco (pulgar + índice): primero apunta un cuadro con el índice hasta que se marque, luego pellizca. Se agarra ese cuadro aunque el dedo se mueva un poco. Arrastra y suelta para que encaje.
  • ✊ Puño: agarra el cubo entero. Mueve el puño para girarlo y abre la mano para soltarlo.
  • ✋ Mano abierta: mano libre, no hace nada. Úsala para descansar o reacomodarte.
  • 🙌 Dos manos abiertas: sepáralas o júntalas para acercar o alejar.
  • ✌️ Dos dedos sostenidos 1 segundo: deshacer.
  • 👍 Pulgar arriba sostenido 1 segundo: hazlo por mí (siguiente paso del guía).
